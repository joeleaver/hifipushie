# Templates

`male_stylized.npz`: the body of Blender Studio's "Human Base Meshes" v1.4.1 (CC0), object GEO-body_male_stylized
(12,502 vertices, 12,500 quads, A-pose, facing -Y), re-centred (x on 0, feet at z = 0). Exported with
`spikes/topology/template/hbm_export.py` from the bundle (blender.org Demo Files, Asset Bundles).
`male_stylized_joints.json`: its skeleton, measured from cross-sections. `male_stylized_face.json`: face landmarks,
skull anchors, and what `retopo` needs (see its `_notes`).
